Mission 1: Supply Ship Attack — North of Scotland
Objective:

Destroy the Merchant Ship before it exits the map, then exit the map in the direction of the red arrow.

Phase 1 — U-Boat Phase

If Medium, DL −1
If Deep, DL −2

Roll 3 dice (2 dice if Engine is Damaged)
*AP this turn = highest die rolled +1 AP if Captain is alive

Phase 2 — Merchant Ships Phase

If Undamaged MOVE 1 Hex
If Damaged roll d6: on 4+ MOVE 1 Hex
Always Face dotted line.

Phase 3 — Detection Phase

Roll 1d6 for each Escort that has the U-Boat in LOS and within 3 hexes.

Each success = +1 DL

Base Detection Roll needed:

Depth	Roll
Surfaced	1+
Periscope	2+
Medium	4+
Deep	5+

Modifiers

Engine Damage: Decrease roll required by 1

Sonar Operator alive: Increase roll required by 1
