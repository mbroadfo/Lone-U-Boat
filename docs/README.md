## Contributing

When adding new documentation:
1. Place current/active docs in `docs/` root
2. Session logs go to `docs/archive/sessions/` immediately
3. Completed phase reports go to `docs/archive/phases/`
4. Implementation details go to `docs/archive/implementations/`
5. Keep root directory clean for user-facing docs
